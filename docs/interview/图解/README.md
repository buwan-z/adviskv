## 三轮背诵法

1. **15 分钟**：图 1、3、6、9、11、17。能说清四个模块、建表何时可用、写成功点、读安全点、选举和恢复。
2. **45 分钟**：按 1–19 顺序，每图用“入口 → 关键状态 → 成功条件 → 失败分支”讲 60–90 秒。
3. **模拟面试**：按[题库 J 节](../分层面试题库.md)的快问与项目深挖顺序回答；答错时回到对应图和源码，而不是只背术语。

最需要主动说明的边界见[证据与边界](../证据与边界.md)：Catalog/Topo 当前是单进程；shard 数建表后固定；KV 运行时使用内存 Map，但 WAL/Snapshot 支持恢复；`request_id` 暂无 TTL。组件图提供 drawio/SVG，流程图使用 Markdown 内嵌 Mermaid。资源编辑方式见[组件图资源说明](../../assets/interview-architecture/README.md)。
